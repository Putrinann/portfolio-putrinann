# Putri Nurul Annisa Portfolio

Modern React and Tailwind CSS personal portfolio for analyst-oriented roles across systems, business process, IT, data, and QA.

## Run Locally

```bash
npm install
npm run dev
```

Local URL:

```text
http://127.0.0.1:5173/
```

## Update Content

Edit portfolio text, links, projects, organizations, certifications, and toolkit items in:

```text
src/data/portfolioData.js
```

## Replace Images

Image placeholders are stored in:

```text
public/images/profile
public/images/projects
public/images/certifications
```

Keep the same filenames for the fastest replacement, or update the `image` paths in `src/data/portfolioData.js`.

Current profile assets:

```text
public/images/profile/putri-standing-heels-cutout.png
public/images/profile/putri-red-background.jpeg
```

For WhatsApp, replace `https://wa.me/` in `contactLinks` with your full international number, for example:

```js
https://wa.me/6281234567890
```
